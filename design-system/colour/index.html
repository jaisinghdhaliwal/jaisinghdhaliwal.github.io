Quiet field.
Clear signal.

01 / Core palette

Five colours carry the interface.

The brand is intentionally restrained. The portfolio imagery already brings variety, so the interface palette should remain stable enough to frame it.

02 / Supporting colours

Support the hierarchy without starting a second palette.

Supporting tones extend the core colours for depth, borders and secondary copy. They should not become prominent brand accents.

Body ink #151923 — the standard reading colour used across the portfolio.
Cloud #ECEBEA — quiet dividers, preview grounds and neutral grouping surfaces.
Structural line Navy at 24% opacity — dividers and heading rules that support the layout without becoming another accent.

03 / Proportion

The accent stays memorable because it stays rare.

This ratio is a working guide for interface chrome, not a pixel quota. Project photography, video and artwork sit outside it because their colour is content rather than branding.

70% Paper 15% White 10% Navy 5% Coral
70% Paper The dominant page field and breathing room around content.
15% White Raised cards, glass panels and areas that need separation from paper.
10% Navy Typography, structural lines, dark surfaces and the main logo form.
5% Coral Active navigation, primary signals, selected states and concise annotations.

04 / Colour roles

Give each colour one clear job.

01

Navy communicates

Use navy for headings, rules, outlines and the lettering within the current logo. It replaces generic black throughout the brand.

02

Coral directs

Use coral for the current location, the strongest call to action, section labels and the holding shape of the primary logo.

03

Paper frames

Use paper as the default canvas. Its warmer tone distinguishes the identity from clinical pure-white interfaces.

04

White lifts

Use white for elevated cards and translucent panels. It should create depth, not become a second dominant page background.

05

Coral soft groups

Use the pale tint for low-emphasis callouts or section changes where a full coral field would be too loud.

05 / Contrast

Accessible combinations are part of the palette.

Contrast values below were calculated from the current hexadecimal colours. Treat 4.5:1 as the minimum for normal-size text and 3:1 for large text and essential interface boundaries. Select any visual sample to load it into the checker.

Combination Ratio Guidance
Navy / Paper 16.08:1 Preferred default for all text sizes.
Navy / White 17.38:1 Preferred for cards, glass panels and form controls.
Navy / Coral soft 15.68:1 Safe for body copy and callout content.
Navy / Coral 5.05:1 The standard combination for selected pills and coral buttons.
White / Coral 3.45:1 Use only for large bold text or non-text UI. It does not pass AA for small body or label text.
Coral / Paper 3.19:1 Suitable for large headings, icons and accents—not small essential text.

07 / Usage

Restraint keeps the work colourful.

Do

Use coral to show state

Active navigation, selected filters and the main call to action are natural signal points.

Avoid

Filling large pages with coral

Large coral fields overpower project imagery and make the accent less effective elsewhere.

Do

Use navy instead of black

Its cool charcoal tone provides near-black contrast while remaining recognisably part of the brand.

Avoid

Sampling accents from projects

Let artwork vary independently. Interface controls should not change colour from project to project.

Do

Check text contrast by role

A combination suitable for a large title may still fail for a 13px navigation label.

Avoid

Using colour as the only cue

Pair selected and error states with text, shape, weight, position or an accessible state attribute.
