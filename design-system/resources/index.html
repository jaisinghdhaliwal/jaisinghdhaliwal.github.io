02 / Logo files

Current artwork, ready to use.

The files in the main logo folder are the current identity set and the source of truth for this website. Earlier concept PNGs are not part of the active system.

Using the filesCurrent
  1. Use SVG for websites, interfaces and scalable digital layouts.
  2. Use the landscape or square mark according to the available shape.
  3. Use the navy name lockup on light surfaces and the white lockup on navy.
  4. Export raster or print files from these SVG sources when a format requires them.

04 / Production

Choose the format for the job.

AssetPreferred formatUse
LogoSVG for screen, vector PDF for printScale without changing master geometry.
Project imageryAVIF/WebP with an appropriate fallback where neededCreate responsive dimensions; retain a high-quality source outside the deployed site.
PhotographyAVIF/WebP for web, high-resolution TIFF/JPEG for printPreserve the intended colour space and original aspect ratio.
ShowreelModern codec plus widely supported MP4 fallbackUse poster imagery, muted inline playback and sensible preload.
Print colourProofed CMYK/process valuesNever assume an RGB hex value predicts the printed result.

05 / Versioning

Keep the system traceable.

Keep the deployed filenames stable and archive superseded working versions outside the public website.

Current public filesSVG

logo-01.svg, logo-02.svg, logo-name-navy.svg, logo-name-white.svg

Do

Record what changed and update every derived export from the current SVG source.

Avoid

Do not mix earlier logo concepts into current applications or distribute raster previews as master artwork.
