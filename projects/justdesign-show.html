The brief

The 2024 Graphic Design Degree Show needed a single digital home for the work of 34 graduating designers. It had to serve general visitors attending the exhibition, industry professionals searching for particular disciplines and students who needed a lasting link to their work after the physical show closed.

I led the five-person student website team through planning and prototyping, contributed to the interface design and then developed the finished site using HTML, CSS, JavaScript and JSON. The work also depended on content supplied by the wider class, so the system needed to accommodate changing biographies, contact details and project media without placing the launch date at risk.

With one shared budget across the degree show, the site was built without a commercial website platform. This kept ongoing costs to the domain name, provided complete control over performance and made it possible to create a content system specifically for the exhibition.

Coordinating a shared exhibition

A shared Miro workspace connected weekly development, responsive design exploration, team responsibilities, dependencies, budget and launch planning. It provided one place for the website team to make decisions while keeping the wider exhibition teams informed as content and requirements changed.

The process turned a large collaborative project into a visible set of responsibilities and dependencies, helping the team respond when content or technical constraints affected another part of the experience.

Visual system

The dark interface created a deliberate contrast with the lighter printed catalogue while retaining the same exhibition identity. Student work remained the most visually varied element, so the surrounding system used restrained typography, recurring symbols and consistent spacing to give 34 different portfolios one coherent frame.

Designing the visitor journey

Exhibition information, animated directions and the student directory were brought into one continuous homepage. The large-screen experience uses horizontal movement to reflect the exhibition's visual character, while the directory returns to familiar vertical scrolling so visitors can scan more students quickly.

The structure serves two different behaviours: casual visitors can explore the show and its identity, while industry visitors can move directly into the directory and filter designers by discipline.

Responsive structure and filtering

The student directory was designed as a repeatable grid with category filters, allowing visitors to narrow the class by relevant skills and disciplines. The same category symbols carry into individual profiles, connecting the overview with the work shown inside each page.

Layouts were adapted around the strengths of each screen size rather than shrinking the desktop interface. The result preserves the exhibition identity while keeping profiles, project media and navigation practical on mobile.

Building a reusable content system

The site needed to manage dozens of profiles and projects without maintaining a separate hard-coded page for every student. A 35KB JSON file became the central source for names, biographies, contact links, categories and project information.

JavaScript uses that data to generate the directory and populate a shared student-profile template. Updating a record in one place carries the change into every interface that uses it, reducing duplication and keeping the class information consistent.

Project media follows the same repeatable structure. Each student's files are grouped under their ID and ordered predictably, allowing the shared project viewer to handle still images and video without creating a different layout for every portfolio.

Performance within a limited budget

Performance was treated as part of the design rather than a final technical check. All student headshots were compressed into a 381KB CSS sprite, reducing repeated image requests while keeping the directory visually immediate.

Each student tile uses its identifier to position the correct portrait from the shared sprite. Project thumbnails use WebP, while larger JPEG, PNG and MP4 media load only inside the relevant profile.

PageSpeed Insights and Lighthouse were used throughout development to test loading, accessibility and technical quality. The launched homepage achieved perfect scores across all four Lighthouse categories during the exhibition.

Launch and outcome

JUSTDESIGN.SHOW launched as the public-facing digital route into the 2024 Degree Show, giving the class one coherent place to present their work before, during and after the exhibition.

The finished system connected exhibition information, animated directions, a filterable directory, 34 student profiles and their selected project work in one responsive experience. Its reusable data and profile structure made a large collection practical to maintain, while its lightweight front end performed strongly during the live event.

The result was more than a promotional page for the exhibition: it gave every participating designer an equal place within one shared digital identity and extended the degree show beyond its temporary physical location.

Created with Loke, Giovanni, Keyi and Zhenli as the five-person student website team. The portraits and projects shown throughout the interface remain the work of the participating Class of 2024 designers.
